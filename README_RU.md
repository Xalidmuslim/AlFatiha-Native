# Аль-Фатиха — Native Android · дизайн 19.05

Это нативная Android-версия. В приложении **нет WebView и нет HTML-интерфейса**.
Исходные учебные данные перенесены из версии 19.04 в JSON assets, а все экраны, кнопки,
навигация, прогресс, настройки и викторины отрисовываются нативными Android View.

## Что уже перенесено
- Главный экран в бежево-шалфейной палитре.
- Осознанное чтение: 8 уроков, глубокий разбор, Ибн аль-Каййим, дополнительные разборы учёных, предисловие.
- Экзамен по осознанному чтению — 30 заданий.
- Викторина: классическая 200, два правильных 20, сопоставление 20, хадис → смысл 30, без вариантов 20, эксперт 20.
- Сохранение прогресса через SharedPreferences.
- Закладки, профиль, статистика, размер шрифта, тёмная тема.
- Нижняя нативная навигация и системная кнопка Назад.

## Сборка бесплатно с Android-телефона
Рекомендуется открыть эту папку как проект в Android IDE/CodeAssist.
В AndroidIDE нажмите ▶. Проект использует Gradle 8.9 и AGP 8.7.3.
Если загрузка Gradle выдаёт ошибку сертификата, выключите VPN/фильтрацию HTTPS и повторите.

APK после debug-сборки: app/build/outputs/apk/debug/app-debug.apk

Package: app.alfatiha.tafsir
Version: 1.0.0-native / versionCode 1
