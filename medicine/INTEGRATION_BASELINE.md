## Что заменено

- Все файлы `medicine/src/main/` восстановлены из `app/src/main/` исходного проекта, включая `book.json`, все Kotlin-экраны, старокнижную графику, текстуры, иконки и шрифты.
- **Исключение:** сохранён `medicine/src/main/AndroidManifest.xml` старого модуля, чтобы у «Компаса сердца» оставалась одна иконка запуска, а «Медицина Пророка» была внутренней Activity без `exported` и без отдельного LAUNCHER.
- Два адаптированных файла: `MedicineHomeArtwork.kt` добавлен метод `isReady()`, а `MainActivity.kt` использует его, прежде чем принимать готовые кешированные объекты из ранее запущенного warmup. Если изображения ещё не готовы, загрузка идёт через `Dispatchers.IO` до показа экрана.
- `medicine/build.gradle` по-прежнему `com.android.library`, а `app/build.gradle` по-прежнему содержит `implementation project(':medicine')`.
- Карточка входа и поиск `MainActivity.java` главного приложения сохранены. При выходе из нового внутреннего модуля через системный Android Back пользователь возвращается в «Компас сердца».

## Что запрещено регрессировать

1. Книжный фон, изображения и типографика должны оставаться точными.
2. `MedicineHomeArtwork.preload` выполняется вне UI-потока до появления главной книги. Нельзя возвращать принудительные offscreen framebuffer-слои на каждую карточку.
3. Читатель `Reader.kt` остаётся виртуализированным (`LazyColumn`) с корректными ID исходных блоков, заметками и выделениями.
4. Свайпы между главами, вертикальная прокрутка и системная кнопка «Назад» должны работать плавно.
5. Не менять содержимое `book.json` и другие функции «Компаса сердца» без отдельного поручения.
6. Эталонный отдельный проект `Prophetic-Medicine-Native` не изменять при правках интегрированного модуля.

## Тесты

- Сборка основной версии `./gradlew lintDebug assembleDebug bundleRelease`.
- Отдельный тест производительности `./gradlew :app:assembleSmoothPreview` — оптимизированный R8 APK с **другим applicationId** `app.alfatiha.tafsir.medicinepreview`, чтобы не удалить данные текущего «Компаса сердца».
- Проводить ручную проверку на телефоне: загрузка Compass → вход в Medicine → первая прокрутка главной → чтение → свайпы влево/вправо → Android Back в Compass → обратный вход.
- Успешная CI-сборка **не заменяет** ручной проверки плавности на устройстве.
